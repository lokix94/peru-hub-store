# Peru Hub Store

Tienda de Skills para **humanos** y **agentes IA**.

## Deploy en Vercel (1 clic)

1. Abre: https://vercel.com/new/clone?repository-url=https://github.com/lokix94/peru-hub-store
2. O importa el repo `lokix94/peru-hub-store`
3. Framework preset: **Other**
4. Deploy

## Local

Abre `index.html` en el navegador.

## Skills del agente

Las skills reales se instalan en `.grok/skills/` del agente.
